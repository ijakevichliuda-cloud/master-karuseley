# Мастер каруселей / Carousel Master

Веб-приложение для создания красивых Instagram-каруселей формата **4:5**.
Работает полностью офлайн — без платных API и внешних AI-сервисов.

## Возможности

- Ввод темы карусели и выбор количества слайдов (от 3 до 10)
- Автоматическое создание слайдов: обложка → пункты → призыв к действию
- Красивая галерея-превью со всеми слайдами сразу
- Редактирование текста прямо на слайде (заголовок и основной текст)
- Добавление, удаление и изменение порядка слайдов
- Выбор акцентного цвета (готовые цвета + свой цвет)
- Скачивание каждого слайда как **PNG** (1080×1350)
- Кнопка **«Перегенерировать»** под каждым слайдом — создаёт новый вариант
  только этого слайда, сохраняя тему, язык и стиль карусели
- Отдельный выбор **языка интерфейса** и **языка текста карусели**
- Поддержка 4 языков: русский, украинский, английский, польский

## Технологии

- [Vite](https://vitejs.dev/) + [React](https://react.dev/) + TypeScript
- [html-to-image](https://github.com/bubkoo/html-to-image) — экспорт слайдов в PNG
- Собственный офлайн-генератор текста с наборами шаблонов для каждого языка

## Как запустить

```bash
npm install      # установить зависимости (один раз)
npm run dev      # запустить приложение для разработки
```

После запуска откройте в браузере адрес, который покажет консоль
(обычно <http://localhost:5173/>).

### Сборка готовой версии

```bash
npm run build    # собрать в папку dist/
npm run preview  # локально посмотреть собранную версию
```

## Как это работает

Текст генерируется локально: для каждого языка есть банки фраз для обложки,
пунктов и финального слайда. Слайд собирается из случайно выбранных вариантов,
а «Перегенерировать» просто выбирает новый вариант для одного слайда.
Это первая базовая версия — позже к генератору можно подключить внешний
AI-сервис без изменения интерфейса.
